## Prisma no bundle da Vercel (causa raiz de "site no ar mas db down")

Sintoma: landing/login 200, `/api/health` → `db: down`,
`PrismaClientInitializationError` sem código, mensagem
`could not locate the Query Engine for runtime "rhel-openssl-3.0.x"`, `latencyMs` baixo.

Causa: o output file tracing do Next **não seguiu o symlink do pnpm** até
`node_modules/.pnpm/@prisma+client@*/node_modules/.prisma/client`, então a lambda foi

Correção (`apps/web/next.config.ts`):
```ts
outputFileTracingIncludes: {
  "/**/*": [
    "../../node_modules/.pnpm/@prisma+client*/node_modules/.prisma/client/**/*",
    "../../node_modules/.prisma/client/**/*",
    "./node_modules/.prisma/client/**/*",
  ],
}
```

Verificação local sem deploy: buildar e conferir
`apps/web/.next/server/app/api/health/route.js.nft.json` — os dois engines
(`debian-openssl-3.0.x` e `rhel-openssl-3.0.x`) precisam estar em `files`.

## Cadastro de aluno + cobrança automática (branch `feat/aluno-e-cobranca-automatica`)

- **Temporada e categoria saíram do produto.** Schema, RLS, telas e docs agora têm
  `class_group` com nome livre; idade vem de `students.birth_date`. `due_day` migrou da
  matrícula/plano para o aluno. Migrações: `20261109120000_turma_sem_temporada`,
  `20261109130000_system_job_directory`. Ao mexer em turma, não procure `season`/`category`.
- **Criar usuário pela app é impossível, e isso é a RLS funcionando**: a política de `users`
  tem `WITH CHECK (id = app.current_user_id())`, então `tx.user.create` de outra pessoa falha
  mesmo com a leitura liberada por vínculo. Quem cria conta é `ensureUser`
  (`packages/auth/src/provision-user.ts`), no cliente dono das tabelas, fora do `withTenant`.
  Usar `ensureUser` para professor/coordenação também.
- **Ordem importa**: `ensureUser` antes da transação. Dentro dela, o Prisma abre outra conexão
  e a transação fica aberta esperando — e o usuário já nasce commitado se a transação falhar
  (órfão sem membresia, inofensivo).
- **`@nextgen/db` instancia o cliente no import**: sem `APP_DATABASE_URL`, qualquer teste que
  importe o package explode na coleta. `apps/web/vitest.setup.ts` põe um placeholder.
- **Janela de cobrança** (`isBillingWindowOpen`): abre D-5 e continua aberta depois do
  vencimento. O e-mail segue a mesma janela mesmo na geração manual, senão a competência
  antecipada vira aviso perdido três semanas antes.
- Cron: `/api/cron/mensalidades`, `Authorization: Bearer $CRON_SECRET`, `withSystemJob` só lê
  `schools` (política `system_school_directory`), e cada escola é uma `withTenant` — `207`
  quando alguma falha.
- Sem Postgres nesta máquina: `psql`/`pg_isready` não existem, então migração e seed só se
  verificam por `prisma validate` + `tsc`. Build do Next roda offline com `BETTER_AUTH_SECRET`
  e URLs falsas.
